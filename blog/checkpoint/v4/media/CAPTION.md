# Vortex merger

Red **+** markers are relative maxima of each panel’s own plotted $\omega$ (re-detected every frame).

**Fidelity note:** peak radii spiral inward similarly to DNS, but peak **angles** largely freeze after early time while DNS keeps co-rotating. Pointwise $\omega$ Rel-$L^2$ can look good ($\le 2\%$) while orbital phase is wrong — the pointwise loss does not penalize co-rotation, and plain time features do not encode a sustained orbit.
